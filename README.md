# Hybrid GATv2–CNN for Cross-Market Bid-Rigging Detection

A two-stage pipeline for tender-level collusion detection: a CNN (Stage 1) extracts
64-dimensional visual embeddings from bid-rotation images of bidder pairs, a
Contextual Bridge Module aggregates them per tender using statistical screens as
query context, and a GATv2 graph network (Stage 2) classifies each tender as
collusive or competitive using the resulting 135-dimensional node features.

The pipeline is explicitly designed to prevent tender-level and country-level data
leakage between Stage 1 (CNN) and Stage 2 (GATv2), and between source and target
countries in the cross-market (LOCO) evaluation. See **Leakage Safety** below for
details — this is not optional configuration, it is enforced by hard failures in
the scripts themselves.

## Data Availability

The raw procurement datasets (Brazil, Japan, USA) used in this study are **not**
included in this repository. They are publicly available from the supplementary
materials of Garcia et al. (2022):
<https://doi.org/10.1016/j.autcon.2021.104047>

Download the three country CSV files and place them under `data/raw/` using the
filenames configured in `config/config.yaml` (see `countries:` section) before
running the pipeline.

All pipeline scripts live directly under `src/` and import shared model
definitions from `src/models/` and configuration helpers from `src/utils/`
(e.g. `from src.models.cnn_model import create_cnn_model`,

adds the project root to `sys.path` at import time, so scripts must be run
from the project root (see commands below).

## Environment Setup

Tested with Python 3.13 on macOS (Apple Silicon, MPS backend). Exact package
versions are pinned in `requirements.txt` (generated via `pip freeze` from the
environment used to produce the results reported in the thesis).

```bash
python -m venv .venv
source .venv/bin/activate           # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

`requirements.txt` includes some macOS-only and Jupyter/IPython development
dependencies (e.g. `appnope`, `ipykernel`) that are not required to run the
pipeline scripts themselves; `appnope` is marked `sys_platform == "darwin"` so
it is skipped automatically on Linux/Windows. If you hit an installation error
on another OS, it is safe to delete the offending line and re-run `pip install`.

On non-Apple-Silicon hardware, PyTorch will fall back to `cuda` (if available)
or `cpu` automatically — see `resolve_device()` in `train_stage2.py`.

## Pipeline (run in order)

Every step reads from `config/config.yaml`; override individual paths with CLI
flags where noted. Run all commands from the project root. Steps 4–9 must be
repeated once for the **pooled** model and once per **LOCO fold** (excluding
Brazil / Japan / USA in turn) — see the LOCO section below for exact commands.

| # | Command | Produces |
|---|---|---|
| 1 | `python src/data_preprocessing.py` | `data/processed/{country}_cleaned.parquet` |
| 2 | `python src/create_tender_splits.py` | `outputs/splits/{country}_split.json` (train/val/test **tender IDs**, fixed before any image is generated) |
| 3 | `python src/image_generator.py` | `outputs/images/{country}_trainonly_*` and `{country}_full_*` (see Leakage Safety) |
| 4 | `python src/train_cnn.py --country all` | Pooled Stage 1 CNN: `outputs/models/pooled_m1/best_cnn.pth` |
| 5 | `python src/extract_embeddings.py --model_dir outputs/models/pooled_m1` | `outputs/embeddings/{country}_pair_embeddings_with_labels.csv` |
| 6 | `python src/prepare_graph_data.py` | `outputs/graph_data/{country}_graph.pt` |
| 7 | `python src/prepare_node_features.py --embedding_csv outputs/embeddings/all_pair_embeddings_with_labels.csv --output_dir outputs/node_features/insample` | `outputs/node_features/insample/{country}_node_features.pt` |
| 8 | `python src/train_stage2.py --model_type {simple_gat,gatv2,hybrid} --node_features_dir outputs/node_features/insample` | In-sample M2 / M3 / M4 results (5 runs each) |
| 9 | `python src/evaluate_baseline.py` | LR / RF baseline results (screens and full feature variants) |
| 10 | `python src/ttest.py` | `outputs/models_stage2/in_sample/ttest/paired_ttest_core.csv` and `..._baseline.csv` |

### Cross-market (LOCO) evaluation

For each target country, train a **separate** Stage 1 CNN using only the other two
countries as source, then extract embeddings, build node features, and train
Stage 2 with that country held out:

```bash
# Example: target = brazil (source = japan, usa)
python src/train_cnn.py --countries japan usa \
    --output_dir outputs/models/fold_brazil

python src/extract_embeddings.py \
    --model_dir outputs/models/fold_brazil \
    --output_dir outputs/embeddings_fold_brazil

python src/prepare_node_features.py \
    --embedding_csv outputs/embeddings_fold_brazil/all_pair_embeddings_with_labels.csv \
    --output_dir outputs/node_features/fold_brazil

python src/train_stage2.py --model_type hybrid \
    --test_country brazil \
    --node_features_dir outputs/node_features/fold_brazil \
    --output_dir outputs/models_stage2 \
    --n_runs 5 --epochs 50                      # C1: zero-shot, local norm (default)

python src/train_stage2.py --model_type hybrid \
    --test_country brazil --global_norm \
    --node_features_dir outputs/node_features/fold_brazil \
    --output_dir outputs/models_stage2 \
    --n_runs 5 --epochs 50                      # C2: zero-shot, global norm

python src/train_stage2.py --model_type hybrid \
    --test_country brazil --global_norm --fine_tune_ratio 0.15 \
    --node_features_dir outputs/node_features/fold_brazil \
    --output_dir outputs/models_stage2 \
    --n_runs 5 --epochs 50                      # C3: few-shot 15%, global norm
```

Repeat for `--countries brazil usa` / `--test_country japan` and
`--countries brazil japan` / `--test_country usa`.

## Leakage Safety

This pipeline enforces two leakage-prevention rules with hard failures, not just
documentation:

1. **Tender-level leakage (Stage 1 → Stage 2).** `create_tender_splits.py` fixes
   train/val/test tender IDs *before* any bid-rotation image exists.
   `image_generator.py` then produces two image sets per country:
   `*_trainonly_*` (built only from train-split tenders — used to train the CNN)
   and `*_full_*` (built from all tenders — used only for frozen-model embedding
   extraction). `train_cnn.py` and `extract_embeddings.py` each refuse to run
   (`assert_trainonly` / `assert_full`) if pointed at the wrong file set.

2. **Country-level leakage (LOCO).** Each LOCO fold trains its own Stage 1 CNN
   using `--countries <source1> <source2>` (excluding the target country
   entirely, including under the few-shot condition — only the Stage 2 GATv2
   classifier is fine-tuned on the 15% labelled target-country subset, never
   the CNN).

Do not merge or reuse embeddings/checkpoints across folds or between the pooled
and LOCO settings.
